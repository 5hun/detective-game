# どうぶつ探偵

動物たちの証言を読み、善人と犯人を見分ける、日本語の論理推理ゲームです。

## 起動

Node.js 20以降で、初回に依存パッケージをインストールし、TypeScriptをビルドしてください。

```sh
npm ci
npm run build
```

ビルド後は **`index.html` をブラウザで開くだけで遊べます。** サーバー起動は不要です。配布するときは `index.html`・`styles.css` と `dist/` 内の `engine.js`・`portraits.js`・`ruby.js`・`sound.js`・`app.js` を、フォルダ構成を保って配置してください。実行時の外部通信は不要です。

PCでは `index.html` をダブルクリックするか、ブラウザにドラッグしてください。スマホの画面幅にも対応しています。ただし、スマホOSやファイル管理アプリによってはローカルHTMLのJavaScript実行を制限します。その場合は、静的ホスティングに同じファイルと `dist/` フォルダを置いてアクセスできます（アプリ用のバックエンドは不要です）。

## 遊び方

- 「新しい事件を捜査」や「次の事件へ」を押すと、ダイアログで難易度を選んで開始できます。キャンセルすると現在の事件を続けられます。
- 「動物一覧」で全8種類と証言ルールを確認できます。
- 「証言を聞く」をタップすると、その動物の発言が公開されます。
- 画面上部の「かん／漢」のルビアイコンでルビを切り替えられます。設定は事件とは別に保存します。
- 漢字にはルビを表示します（選択欄・入力欄の案内はかな表記）。
- 冒頭に6種類の事件名と短い説明を表示します。同じ事件を再開すると、説明も引き継がれます。
- 事件の内訳・発見した犯人数・残り信用は、スクロール中も画面上部に表示します。
- 事件ごとに犯人と善人の数が決まっています。
- 善人の発言は必ず正しく、犯人の発言は必ず間違っています。
- 真相は事件ごとに1つに固定されていますが、証言と人数の条件に合う組み合わせが複数残る場合もあります。信用を使って判定し、正体を確かめる必要があります。
- 各動物の「犯人と判定」で、その場で正体が判明します。犯人をすべて見つけると残りは自動で善人と確定し、善人を判定する操作は不要です。
- 判定した動物は、正体に合わせて絵が変わります。善人を誤判定すると悲しい顔になり、格子は表示しません。犯人は困った表情と格子で表示し、事件解決で自動確定した善人は笑顔になります。
- 判定時は正解・不正解に応じた短い効果音が鳴ります。スピーカーアイコンで切り替えられ、設定は保存されます。音はブラウザ内で生成し、音声ファイルや通信は不要です。
- 誤判定すると信用が2減ります。誤判定した相手も判定済みになります。
- 信用は5から開始し、正解で1増え（その動物の証言を聞く前なら2増え）、不正解で2減ります。信用が0になると捜査終了です。信用が残った状態で犯人をすべて見つけると解決です。自動で確定した善人の分は信用を増やしません。
- メモとマーカー（未設定・犯人候補・善人候補・要検討）は自由に使え、判定には影響しません。
- 終了時は中央に結果ダイアログを表示します。閉じた後もページ上に結果と「次の事件へ」が残ります。
- 終了後は各証言と真相の照合を確認できます。

| 難易度 | 数 | 犯人 |
| --- | ---: | ---: |
| かんたん | 4 | 1 |
| ふつう | 5 | 2 |
| むずかしい | 7 | 3 |

8種類の動物から重複なしで登場し、種類ごとに証言の論理形式が異なります。どの動物も善人・犯人の両方になれます。

## 保存

保存データのバージョンや形式・内容が現行仕様と一致しない場合は、データなしとして新しい事件を開始します。旧形式からの移行は行いません。

進行状況、公開した証言、メモ、マーカーをブラウザの `localStorage` に自動保存します。保存できない環境でもプレイ可能ですが、画面を閉じると進行状況は失われます。ローカルファイルの保存領域はブラウザごとに扱いが異なり、別の場所に移動した場合やプライベートブラウズでは引き継げない場合があります。

## 実装と検証

HTML/CSS/TypeScriptで実装しています。実行時の依存ライブラリはありません。TypeScriptは `strict` モードで検査し、`dist/` にJavaScriptを出力します。ゲーム状態・難易度・証言・ブラウザAPIの型は `types.d.ts` で共有しています。生成ファイルと `node_modules/` はGit管理対象外です。ソースを変更したら再度 `npm run build` を実行してください。動物のオリジナルドット絵はSVGの矩形で描画しています。生成器は数の条件を満たす組み合わせから真相を1つ選び、各動物の立場に合う証言をランダムに選びます。証言から真相が一意に決まることは保証せず、判定は固定された真相に基づきます。保存された乱数シードで同じ問題を再現できます。

Node.js 20以降で、3難易度・計3,000問の独立した全探索検証と、信用／勝敗／再現性のテストを実行できます。

```sh
npm run typecheck
npm test
```

ブラウザテスト（初回にChromiumをインストール）:

```sh
npx playwright install chromium
npm run test:browser
```

既存の環境を使う場合、`PLAYWRIGHT_MODULE` にPlaywrightパッケージのパス、`CHROMIUM_PATH` にChromium実行ファイルのパスを指定できます。テストは `file://` で開き、メモ・マーカーの保存、勝敗、難易度、ダイアログ、320px／390pxの横幅、保存不可の場合を確認します。スクリーンショットは `/tmp/beast-detective-desktop.png` と `/tmp/beast-detective-mobile.png` に保存します。
